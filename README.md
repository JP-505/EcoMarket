# EcoMarket Mosquera - Marketplace 2.0 (Taller 5)

Aplicación móvil desarrollada en **React Native (Expo)** como evolución del sistema de comercio electrónico local, integrando variantes de productos, comparador, filtros combinados, libreta de direcciones, seguimiento de pedidos por estados, cancelaciones con reintegro de inventario, centro de notificaciones y soporte posventa.
